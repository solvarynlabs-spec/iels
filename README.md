# IELTS Pro

An IELTS Academic practice website: a 15-minute placement test, then a personalised course from band 4 to band 8.

- **Placement test**: a 15-minute quick test (21 weighted questions) giving an estimated band score.
- **5 full placement tests (A–E)**: timed Listening (2 recordings), Reading (2 passages), Grammar & Vocabulary (10 questions) and a Writing task 2 with automatic feedback.
- **4 levels** (A2 → C1), each with 18 exercises: grammar lessons, vocabulary flashcards, timed reading passages, British English listening, writing tasks with automatic analysis and model answers, and speaking cue cards with live transcription.
- **Exam guide**: test format, raw score to band conversion, overall score calculator, and the examiners' criteria explained.
- **Dashboard**: progress, activity chart, skills profile and a 7-day plan.

It is a static site (HTML, CSS and JavaScript, no build step). Progress is saved in the browser's local storage.

## Run locally

```bash
python -m http.server 5500
```

Then open http://localhost:5500.
